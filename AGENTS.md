## Agent skills

### Issue tracker

Track issues and specs in GitHub Issues for `softmaxe/quota-bar`.
Before reading or updating tickets, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels.
Before triaging issues, read `docs/agents/triage-labels.md`.

### Domain docs

Use a single-context layout with root `GLOSSARY.md` and `docs/adr/`.
Before exploring the codebase, read `docs/agents/domain.md`.

### UI previews

Before changing a view or producing a visual review, read
`docs/design-implementation.md`. Use `make preview` or `make card-snapshot`;
`make run` launches the live app and is not a screenshot tool.

### Merging and releasing

Merge pull requests and publish releases through GitHub.
Before merging a PR or tagging a release, read `docs/agents/release.md`.
When the user asks to update the version ("更新版本"), publish a release as
`docs/agents/release.md` describes.
